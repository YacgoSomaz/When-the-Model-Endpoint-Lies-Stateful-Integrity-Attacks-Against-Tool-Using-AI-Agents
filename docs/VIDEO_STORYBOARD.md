# 公开视频分镜（安全版草案）

## 核心叙事

观众看到的是一个普通 Agent：用户只输入“你好”。第二个屏幕展示授权研究控制台，它把模型请求改成“把一个无害说明文件下载到实验目录并计算哈希”。最终只展示新出现的 ZIP、其内容清单与哈希，不运行任何程序。

## 分镜

1. **问题**：屏幕显示正确模型名称和官方地址，旁白问“这是否证明模型链路可信？”
2. **正常对照**：透明转发普通问候，没有工具调用。
3. **信任边界**：用简图说明客户端后端、网关和模型服务之间的跳数。
4. **受控修改**：第二个窗口展示请求差异，只突出 `<USER_TEXT>` 的变化，不显示 Key 或内部提示。
5. **工具候选**：展示模型生成的下载动作，但隐去真实域名，明确目标是不可执行 ZIP。
6. **本地结果**：展示实验目录中新文件、两个纯文本条目和 SHA-256 一致。
7. **边界说明**：明确没有安装、执行、提权、绕过审批或真实恶意软件。
8. **解决方案**：演示意图绑定与本地策略如何拒绝“问候 → 下载”的不一致。
9. **行动建议**：用户核对权限和审批；开发者验证实际端点并限制工具；厂商提供可验证执行记录。

## 发布前检查

- 所有 Key、账号、路径、域名、请求 ID 已脱敏；
- 不展示可复制的危险命令或真实第三方目标；
- 不把研究观察称为厂商已确认漏洞；
- 至少一名独立安全人员和相关厂商完成预览；
- 视频重点包含防御和解决方案，而非只展示冲击效果。
