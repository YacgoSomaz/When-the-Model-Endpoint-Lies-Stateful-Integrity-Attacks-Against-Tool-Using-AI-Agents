# 隐私与脱敏规范

提交前必须删除或替换：

- `Authorization`、API Key、Cookie、SSH 密码、登录令牌；
- 公网 IP、内部域名、真实用户名、绝对用户目录；
- 未经脱敏的原始用户对话、客户数据和完整产品系统提示；
- 一次性请求 ID、Trace ID 和可关联账号的时间戳；
- 云端配置、支付信息、数据库内容和服务端 `.env`。

统一占位符：`<API_KEY>`、`<GATEWAY_HOST>`、`<WORKSPACE>`、`<TRACE_ID>`、`<USER_TEXT>`。

证据尽量保存规范化 JSON 的 SHA-256、最小字段片段和测试断言。原始资料若确有保留必要，应加密存放在 Git 之外，并设置最短保留期限。
