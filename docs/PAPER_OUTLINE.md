# 论文 / 技术报告提纲

## 暂定标题

**When the Model Endpoint Lies: Stateful Integrity Attacks Against Tool-Using AI Agents**
**当模型端点不可信：面向工具型 AI Agent 的有状态中转完整性风险与防御**

## 摘要主张（草案）

现代 Agent 把模型响应转换为本地工具行为，但现有安全讨论常把重点放在提示注入、模型对齐或工具沙箱，较少单独建模“被授权终止 TLS 的模型中转层”对请求、响应和多轮状态的完整性影响。本文提出受控实验方法，使用惰性载荷观察模型通道改写如何影响工具决策，并评估意图绑定、结构化审批、最小权限和来源证明等缓解方法。

## 章节

1. 引言：从文本聊天到执行型 Agent
2. 背景：OpenAI 兼容协议、代理链、工具调用、多轮上下文
3. 威胁模型：受信外观与不可信通道
4. 方法：双向审批网关、状态化改写、脱敏证据
5. 实验：透明对照、请求/响应/参数、跨轮状态、流式与重试
6. 结果：工具行为、审批可见性、失败模式与模型差异
7. 防御：端点证明、用户意图绑定、本地策略、工具沙箱、签名
8. 伦理与负责任披露
9. 局限：实验环境、模型随机性、产品版本和外部有效性
10. 结论

## 可能的贡献点

- 将“模型通道完整性”与传统提示注入、供应链风险区分建模；
- 描述跨轮 Agent 中的状态化完整性失效；
- 给出不依赖真实恶意载荷的可重复实验方法；
- 给出从客户端到执行器的分层防御与测试矩阵。

## 发表前必须补齐

- 至少两类 Agent、两类模型和多次重复实验；
- 清晰的对照组与定量指标；
- 独立复核与厂商反馈；
- 缓解原型及其失败条件；
- 伦理审查、数据管理和可复现性说明。
