# Contributing

This repository is private and pre-disclosure. Contributions must improve
measurement, reproducibility, redaction, or defenses.

Before opening a pull request:

1. Read `ETHICS.md` and keep all tests inside authorized systems.
2. Use inert artifacts and a dedicated workspace.
3. Add or update a unit test for code changes.
4. Run the artifact verifier and secret scanner.
5. Do not include raw product prompts, credentials, user records, or live infrastructure.
6. Describe both what the evidence proves and what it does not prove.

Changes that add executable payloads, credential access, persistence, privilege
escalation, stealth, or third-party targeting will not be accepted.
